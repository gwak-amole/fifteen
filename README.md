# fifteen
This was my submission to the GMTK game jam!
In this game, you're Agent Fifteen. You're in charge with the imprisonment of Alex Miller, the head of an international illegal arms dealing association.

## Controls
I can't stress this enough, but you must HOLD R to rewind! Tapping shortly isn't enough!
- WASD / arrows to move
- e to interact, general 'ok' button
- **HOLD** r to rewind time
- click with mouse to inspect

## Notes about rewinding:
- You can only rewind twice
- Each time you rewind, Miller comes home faster (he's onto the fact that you're rewinding)
